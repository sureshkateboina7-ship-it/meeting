This folder contains the upgraded YOLO weight files used by the project:

- `helmet_model.pt`
  Source: `https://huggingface.co/keremberke/yolov8m-hard-hat-detection`
- `plate_model.pt`
  Source: `https://huggingface.co/Koushim/yolov8-license-plate-detection`

The application loads these files with Ultralytics YOLO for real inference.
