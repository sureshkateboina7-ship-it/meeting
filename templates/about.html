System Details

Model & Pipeline

YOLO-based rider and plate detection with OCR, violation storage, and email alerts.

About

This system uses Ultralytics YOLOv8 for rider/helmet detection and ALPR/OCR for extracting registration text from detected plate regions.

Implemented pipeline: Frame -> Helmet Detection -> Bike-rider validation -> No Helmet violation -> Rider/Bike-guided Plate Detection -> OCR -> SQLite Save with annotated evidence -> SMTP Email Alert.

The project follows MVT principles in Flask: Model Layer (`services`, `database`), Views (`views`), and Templates (`templates`).
